# System Health & Metrics Dashboard

This directory contains automated system health reports and metrics generated by the autonomous backlog management system.

## File Structure

- `system_health_YYYY-MM-DD.json` - Daily system health snapshots
- `metrics_YYYY-MM-DD.md` - Human-readable metrics reports  
- `backlog_wsjf_YYYY-MM-DD.json` - WSJF scoring snapshots

## Metrics Schema

Each JSON report contains:

### Core Metrics
- `timestamp` - Report generation time
- `completed_ids` - List of completed backlog item IDs
- `coverage_delta` - Test coverage change
- `flaky_tests` - List of unstable tests
- `ci_summary` - Build and test status

### Backlog Health  
- `open_prs` - Active pull requests
- `risks_or_blocks` - Blocked items requiring attention
- `backlog_size_by_status` - Items by workflow state
- `avg_cycle_time` - Development velocity metric
- `wsjf_snapshot` - Current prioritization state

### System Health
- `dependencies_installed` - Infrastructure status
- `test_infrastructure` - CI/CD health
- `code_quality` - Static analysis results
- `security_posture` - Security scan status
- `performance_status` - Performance metrics
- `documentation_status` - Docs completeness

## Autonomous Session Tracking

Each report includes autonomous session metadata:
- Discovery results
- Items executed  
- System improvements made
- Recommended next actions

## Usage

These reports enable:
1. **Continuous monitoring** of system health
2. **Trend analysis** of development velocity  
3. **Early detection** of quality regressions
4. **Evidence-based** prioritization decisions
5. **Autonomous operation** oversight

Reports are generated automatically after each significant system change or daily if no changes occur.
